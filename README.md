# 🟡 بوت أسعار الذهب - الدولار والريال اليمني

بوت تيليجرام ينشر يوميًا سعر الذهب بالدولار الأمريكي، محوّلًا للريال اليمني
حسب سعر الصرف في صنعاء وعدن، بتصميم رسائل منسق واحترافي.

## المصادر
- 💰 الذهب: gold-api.com (مجاني، بدون مفتاح)
- 💵 الصرف: exrye.com (صنعاء + عدن)

## التشغيل محليًا (Termux)
1. انسخ `.env.example` إلى `.env` واملأ `BOT_TOKEN` و `CHAT_ID`
2. `pip install -r requirements.txt`
3. `python bot.py`

## النشر على Railway
1. اربط هذا الريبو بمشروع جديد في Railway
2. من تبويب Variables أضف: `BOT_TOKEN`, `CHAT_ID`, (اختياري) `DAILY_HOUR`, `DAILY_MINUTE`
3. Railway يكتشف `Procfile` تلقائيًا ويشغّل البوت كـ worker دائم

## الأوامر
- `/start` — رسالة ترحيب
- `/price` — السعر الحالي فورًا
